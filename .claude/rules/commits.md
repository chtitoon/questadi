# Commit conventions

Always use [Conventional Commits](https://www.conventionalcommits.org/) for every commit in this repo.

Format: `type(scope): description`

Types: `feat`, `fix`, `chore`, `refactor`, `docs`, `style`, `test`, `build`, `ci`

Examples:
- `feat(web): add favicon`
- `fix(api): correct OTP validation`
- `chore(design): update design tokens`
